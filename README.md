# نظام نقاط البيع للمطاعم - Restaurant POS System

نظام نقاط بيع متكامل للمطاعم يدعم اللغة العربية والإنجليزية، مع ميزات متقدمة تشمل إدارة المخزون، الورديات، المرتجعات، والتقارير.

## المميزات الرئيسية

### ✅ المميزات الأساسية
- واجهة مستخدم تفاعلية تعمل باللمس (Touch-First Design)
- نظام تسجيل دخول آمن بأدوار مختلفة (Admin, Manager, Cashier)
- نظام ورديات كامل مع إدارة الخزينة
- نظام فواتير كامل مع دعم الضريبة (ZATCA)
- نظام مرتجعات مرن
- طباعة حرارية للفواتير

### ✅ المميزات المتقدمة (النسخة 3.0)
- **تكامل تام مع التليجرام 🤖**: إرسال أكثر من 15 نوع من التقارير التلقائية (فتح/إغلاق وردية، مبيعات، تنبيهات المخزون... الخ) لتكون إدارتك للمطعم في جيبك لحظة بلحظة.
- **إدارة ذكية بالقوالب (AI-Ready) 🧠**: جميع القوائم (المنيو)، المكونات، والوصفات يمكن استيرادها وتصديرها كقوالب CSV جاهزة. هذا يتيح لك الاستعانة بنماذج الذكاء الاصطناعي (AI) بكل سهولة لتوليد، كتابة، وتعديل القوائم ووصفات المطعم بسرعة هائلة ورفعها للنظام بضغطة زر!
- **نظام المكونات والوصفات**: إدارة دقيقة للمكونات وربطها بالمنتجات لحساب التكلفة.
- **ZATCA QR Code**: دعم الفاتورة الإلكترونية السعودية.
- **النسخ الاحتياطي**: نسخ احتياطي تلقائي وآمن.
- **طباعة تذكرة المطبخ**: تنظيم سلس بين الكاشير والمطبخ.

## التثبيت والاستخدام (للمستخدم العادي)

الطريقة الأسهل والأسرع للبدء في استخدام النظام هي من خلال برنامج التثبيت الجاهز:

1. اذهب إلى قسم **[Releases](../../releases)** في هذا المستودع.
2. قم بتحميل أحدث إصدار من ملف التثبيت: `RestaurantPOS_Setup.exe`
3. قم بتشغيل الملف واتبع خطوات التثبيت البسيطة (يدعم التثبيت باللغتين العربية والإنجليزية).
4. بمجرد الانتهاء، ستجد اختصار النظام على سطح المكتب بأيقونته المميزة، قم بتشغيله وابدأ البيع فوراً!

> **ملاحظة:** البرنامج يعمل كلياً بشكل محلي ولا يحتاج لصلاحيات مسؤول، حيث يقوم بإنشاء قاعدة بياناته الخاصة بشكل آمن في مجلد التطبيقات الخاص بالمستخدم.

## للمطورين (تشغيل من الكود المصدري)

إذا كنت مطوراً وترغب في التعديل على النظام، هذه هي المتطلبات الأساسية للتشغيل:

```bash
PyQt5==5.15.10
qrcode==7.4.2
openpyxl==3.1.2
requests==2.31.0
loguru==0.7.2
Pillow==10.0.1
```

لتشغيل النظام من الكود:
```bash
# استنساخ المستودع
git clone https://github.com/SMSMy/POS.git
cd POS

# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل التطبيق
python main.py
```

## الاستخدام الأول

1. **تسجيل الدخول الافتراضي:**
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

2. **فتح وردية جديدة:**
   - اذهب إلى "الورديات"
   - اضغط "فتح وردية جديدة"
   - أدخل المبلغ الافتتاحي

3. **البدء في البيع:**
   - اذهب إلى "نقطة البيع"
   - اختر المنتجات
   - اضغط "إتمام الدفع"

## قاعدة البيانات

يتم إنشاء قاعدة بيانات SQLite تلقائياً عند أول تشغيل. تحتوي على الجداول التالية:

- `users`: المستخدمين
- `categories`: الفئات
- `products`: المنتجات
- `ingredients`: المكونات
- `recipes`: الوصفات
- `shifts`: الورديات
- `invoices`: الفواتير
- `invoice_items`: عناصر الفاتورة
- `payments`: الدفعات
- `cash_movements`: الحركات النقدية
- `returns`: المرتجعات
- `settings`: الإعدادات

لإرسال التقارير عبر التليجرام:

2. احصل على Bot Token
3. أضف البوت لمجموعتك
4. احصل على Chat ID
5. أدخل البيانات في الإعدادات

## ZATCA (الفاتورة الإلكترونية)

يتم توليد QR Code تلقائياً وفقاً لمعايير ZATCA:

- اسم البائع
- الرقم الضريبي
- التاريخ والوقت
- الإجمالي شامل الضريبة
- مبلغ الضريبة
