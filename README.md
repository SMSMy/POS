# نظام نقاط البيع للمطاعم - Restaurant POS System

نظام نقاط بيع متكامل للمطاعم يدعم اللغة العربية والإنجليزية، مع ميزات متقدمة تشمل إدارة المخزون، الورديات، المرتجعات، والتقارير.

## المميزات الرئيسية

### ✅ المميزات الأساسية
- واجهة مستخدم تفاعلية تعمل باللمس (Touch-First Design)
- نظام تسجيل دخول آمن بأدوار مختلفة (Admin, Manager, Cashier)
- نظام ورديات كامل مع إدارة الخزينة
- نظام فواتير كامل مع دعم الضريبة (ZATCA)
- نظام مرتجعات مرن
- طباعة حرارية للفواتير

### ✅ المميزات المتقدمة (النسخة 2.0)
- **نظام المكونات والوصفات**: إدارة المكونات وربطها بالمنتجات
- **ZATCA QR Code**: دعم الفاتورة الإلكترونية السعودية
- **التليجرام**: إرسال 15+ تقرير تلقائياً
- **النسخ الاحتياطي والتعافي**: نسخ احتياطي تلقائي
- **طباعة تذكرة المطبخ**: طباعة تذاكر للمطبخ
- **استيراد/تصدير CSV**: للمنتجات والفئات والمكونات

### ✅ التقارير
- تقرير المبيعات اليومية والشهرية
- تقرير المخزون ومنتجات منخفضة المخزون
- تقرير الورديات والحركات النقدية
- تقرير المرتجعات
- تقرير الربحية

## التثبيت

### الطريقة 1: من الكود المصدري

```bash
# استنساخ المستودع
git clone https://github.com/your-repo/restaurant-pos.git
cd restaurant-pos

# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل التطبيق
python main.py
```

### الطريقة 2: باستخدام PyInstaller (Windows)

```bash
# تثبيت PyInstaller
pip install pyinstaller

# بناء التطبيق
pyinstaller --onefile --windowed --icon=icon.ico main.py

# تشغيل من المجلد dist
dist/main.exe
```

## الاستخدام الأول

1. **تسجيل الدخول الافتراضي:**
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

2. **فتح وردية جديدة:**
   - اذهب إلى "الورديات"
   - اضغط "فتح وردية جديدة"
   - أدخل المبلغ الافتتاحي

3. **البدء في البيع:**
   - اذهب إلى "نقطة البيع"
   - اختر المنتجات
   - اضغط "إتمام الدفع"

## قاعدة البيانات

يتم إنشاء قاعدة بيانات SQLite تلقائياً عند أول تشغيل. تحتوي على الجداول التالية:

- `users`: المستخدمين
- `categories`: الفئات
- `products`: المنتجات
- `ingredients`: المكونات
- `recipes`: الوصفات
- `shifts`: الورديات
- `invoices`: الفواتير
- `invoice_items`: عناصر الفاتورة
- `payments`: الدفعات
- `cash_movements`: الحركات النقدية
- `returns`: المرتجعات
- `settings`: الإعدادات

## الترجمة

النظام يدعم اللغتين العربية والإنجليزية. يتم تحديد اللغة من الإعدادات.

## التليجرام

لإرسال التقارير عبر التليجرام:

1. أنشئ بوت جديد على @BotFather
2. احصل على Bot Token
3. أضف البوت لمجموعتك
4. احصل على Chat ID
5. أدخل البيانات في الإعدادات

## ZATCA (الفاتورة الإلكترونية)

يتم توليد QR Code تلقائياً وفقاً لمعايير ZATCA:

- اسم البائع
- الرقم الضريبي
- التاريخ والوقت
- الإجمالي شامل الضريبة
- مبلغ الضريبة

## النسخ الاحتياطي

يتم إنشاء نسخ احتياطية تلقائياً يومياً. يمكن استعادة النسخ من واجهة الإعدادات.
